Results you can measure

Super Converter aims for “you can't tell” first and file size second, and an automated quality bench holds it to every promise below.

1 Introduction

When a text file becomes a PDF, it should look as if it came out of pdflatex: the same fonts, the same sizes and spacing, and lines broken a whole paragraph at a time.1

Nothing needs a TeX installation, and the text stays real: selectable, searchable and tagged.

eiπ + 1 = 0

1Knuth and Plass, “Breaking paragraphs into lines”, 1981.

Typeset like LaTeX

Markdown, text, HTML, e-books and, if you choose, office files become PDFs with LaTeX's look: Latin Modern at its optical sizes, Knuth–Plass line breaking with TeX's hyphenation patterns, microtype protrusion, TeX math, footnotes and booktabs tables. The sample is set in Latin Modern Roman.

Colour, kept exactly

Colour is managed end to end with ColorSync. A profile the new format can hold is copied byte for byte; otherwise colours are converted once. Pictures that need no change are copied bit-exact.

Sound and video, left alone

Lossless audio chains are bit-exact. Video encodes at constant quality and keeps its colour tags and HDR where the target can carry them, and streams that fit the new container are copied without re-encoding.

Measured on every change

The quality bench converts a fixed corpus through the same engines as the app and measures the results. It runs on every push, and a metric that gets worse fails even when it is still above its threshold.

Your files never leave your Mac

No account, no analytics, no crash reports, no upload. Converting happens on this Mac, and the tools it runs have no network access at all.

The only times it goes online

  • Checking for updatesA request to GitHub Releases for the latest version, with no identifier and no file names. Turn it off in Settings › General.
  • A helper you installOnly when you click Install: that helper's pinned download, checked against its SHA-256 and signature before it runs.
  • Tectonic's first runOnce, right after you install it, Tectonic fetches the TeX packages it needs. Every later run is offline.
  • Web resources of one HTML fileOnly if you turn on “Load web resources” for that file: the pictures and styles the page itself asks for.
